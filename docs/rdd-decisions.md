## Open Questions

- [ ] カード裏面デザインのアートディレクション（独自ロゴ / 汎用パターン / 単色）— §10.4 に「Baccarat aesthetics」記載あるが具体物が未確定
- [ ] ランダムシードの扱い（再現性のためにシード保存するか、毎回 SecureRandom か）— rdd.md に記述なし、デバッグ容易性 vs 公平性のトレードオフ
- [ ] ブラウザの「戻る」操作（Settings 画面からの hardware/browser back）の取り扱い — Flutter Web の Navigator 設計との相性確認が必要
- [ ] アニメーション持続時間の具体値（Flop flip / Turn flip / Squeeze ハプティクス間隔）— UI 実装時の詳細詰めが必要
- [ ] Equity 計算の WebWorker / Isolate 化の必要性 — Flutter Web で重い MC 計算が UI スレッドをブロックする場合の対処
- [ ] 同点判定における highlight per-player 分割表示の詳細 (#7 で「ボード一括」とした上で、ホールカードのみ per-player 表示でよいか確認)
